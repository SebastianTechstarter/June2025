# 🤔 Reflexionsfragen zu Kapitel 1.1

## Die Entwicklung von Linux und gängige Betriebssysteme

**Frage 1:** 
Linus Torvalds begann 1991 mit der Entwicklung von Linux. Warum war es damals schwierig, ein erschwingliches Unix-System auf x86-Computern zu bekommen? Was war der Hauptgrund für Linus, ein eigenes Betriebssystem zu entwickeln?

- Unix-Lizenzen waren sehr teuer und nur auf teuren Workstations verbreitet
    - Also: teuer und nicht frei verfügbar
- Torvalds wollte ein frei verfügbares Unix-ähnliches Betriebssystem
- Außerdem Kontrolle über das System haben, um es ggf weiterentwickeln zu können.

**Frage 2:**
Was ist der grundlegende Unterschied zwischen Linux als Kernel und einer Linux-Distribution? Erkläre mit eigenen Worten, warum es so viele verschiedene Distributionen gibt.
- Ein Kernel ist der Kern des Betriebssystem und steuert Hardware bzw. sorgt dafür, dass Programme laufen können. Es ist aber kein komplettes Betriebssystem.
- Eine Distribution ist ein vollständiges Betriebssystem, das alles enthält, damit der Computer genutzt werden kann.
- Die Nutzer haben unterschiedliche Anforderungen, auf die die unterschiedlichen Distributionen eingehen. So ist für einen alten Computer eine andere Distribution sinnvoll als für einen Server oder den Computer eines Grafikdesigners.

**Frage 3:**
Vergleiche die Debian- und Red Hat-Distributionsfamilien:
- Welche Paketmanager verwenden sie?
    - Debian: APT (Advanced Package Tool)
    - Red Hat: RPM (Red Hat Package Manager)
- Nenne je zwei Beispiele für Distributionen aus jeder Familie
    - Debian: Ubuntu; Linux Mint
    - Red-Hat: Red Hat Enterprise Linux (RHEL); CentOS
- Für welche Anwendungsfälle sind sie optimiert?
    - Debian: Für Server und Desktop-PCs. Läuft stabil und daher gut für Server, bei denen es auf Zuverlässigkeit ankommt
    - Red Hat: Eignet sich für (große) Unternehmen, mit besonderem Fokus auf Support, Sicherheit und Stabilität

**Frage 4:**
Embedded Systeme mit Linux sind heute überall. Erkläre an drei konkreten Beispielen aus deinem Alltag, wo du wahrscheinlich schon Linux-basierte Systeme verwendet hast, ohne es zu wissen.
- WLAN- Router: Viele Heimrouter laufen mit Linux, weil es stabil und anpassbar ist.
- Android-Smartphone: Multimedia- und Netzwerkdienste werden vollumfänglich unterstützt
- Bordcomputer im Auto: Navigation, Mediensteuerung und Bordinformationen 

**Frage 5:**
Android basiert auf dem Linux-Kernel, fühlt sich aber ganz anders an als Ubuntu oder Debian. Erkläre, warum das so ist und welche Vorteile Linux für mobile Geräte bietet.
- Nur der Kernel ist gleich, die Benutzeroberfläche und alle für Mobilgeräte optimierte Systeme (z.B. Touchscreen) wurden extra für die Anwendung auf Mobilgeräten entwickelt. 
    Desktop-Linux ist auf Tastatur und Maus ausgerichtet.

**Frage 6:**
Cloud Computing und Linux sind eng miteinander verbunden. Warum dominiert Linux im Cloud-Bereich so stark? Welche Eigenschaften von Linux machen es für Cloud-Anwendungen besonders geeignet?
- Linux läuft stabil, ohne neustarten zu müssen. (Ideal für Dienste, die 24h erreichbar sien müssen)
- Keine Lizenzgebühren
- Modularer Aufbau  von Linux: Es können die Komponenten integriert werden, die auch gebraucht werden. Spart Speicherplatz

**Frage 7:** *(Weiterdenken)*
Stell dir vor, du müsstest für folgende Szenarien jeweils eine Linux-Distribution empfehlen. Begründe deine Wahl:
- Ein kleines Unternehmen möchte Kosten sparen und von Windows wechseln
    - Ubuntu: Änhlich wie Windows aufgebaut, große Community (Hilfe leicht zu finden), Kompatibel mit Office-Anwendungen
- Ein Entwickler braucht ein System für Webentwicklung
    - Arch Linux: Für erfahrene Nutzer, maximale Anpassung
- Eine Schule möchte alte Computer wieder nutzbar machen
    - Linux-Lite: Ressourcenschonend, einfache Benutzeroberfläche, vorinstallierte Office-Software
- Ein Raspberry Pi-Projekt für Hausautomation
    - Raspbian: Extra für Raspberry optimiert, große Community (Hilfe und Tutorials), schlanke Software (ressourcenschonend)
